# Admin V4.1 quick guide

`/admin` opens the control panel.

- Broadcast: tap Broadcast, then send the next message.
- Ban/Unban: tap it, then send a Telegram user ID or username.
- Services: toggle each platform immediately.
- Rate limit: send a number; 0 means unlimited.
- Force Join: send `@Channel | https://t.me/Channel`; send `off` to disable.
- Maintenance: toggle with one tap. Admins keep access.
- Errors: shows the latest 10 recorded errors.
